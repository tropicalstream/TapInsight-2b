Android/data/<app>/files/Media

⚠ This is Android app-private storage. On Android 11+ it's hidden from desktop file browsers by default and may not be reachable without sideloading tools. The Upload button in this page is the supported path; the instructions below are for advanced cases.

🍎 Mac
  1. Install Android File Transfer (free from Google) — macOS doesn't speak MTP natively.
  2. Plug the glasses in via USB. On the glasses, pull down the notification shade and set USB mode to File transfer (MTP).
  3. Open Android File Transfer (it auto-launches on connection). Navigate to Android/data/…/files/Media.
  4. If the Android/data folder doesn't appear: the glasses' MTP layer is hiding it. Use the companion app's Upload button instead, or use ADB: adb push /local/file /storage/emulated/0/<path>.
🪟 Windows
  1. Plug glasses in via USB and switch USB mode to File transfer (MTP).
  2. Open File Explorer — the glasses appear under This PC.
  3. Navigate to Internal storage\Android\data\…\files\Media.
🐧 Linux / ADB (any OS)
  1. Enable developer mode + USB debugging on the glasses (one-time).
  2. Push files via ADB:
    adb push ~/photo.jpg /storage/emulated/0/Android/data/…/files/Media/Photos/

How the Library Works

Folder Layout

Your media lives at:

…
  • Music/ — default audio folder
  • Videos/ — default video folder
  • Playlists/ — default .m3u/.m3u8 folder, including IP-radio station lists
  • Text/ — default folder for readable text/TTS files
  • Nested folders are fully supported
  • Each folder can have its own .m3u

Playlists (M3U)

Paths inside a .m3u file are relative to the playlist's own directory. Example:

#EXTM3U
#EXTINF:180,Morning Coffee
coffee.mp3
#EXTINF:240,Subway Ride
../Videos/commute.mp4

Auto-generate (top toolbar) creates a .m3u for the current folder, listing every playable file in order.

Supported Formats

  • Audio: mp3, m4a, aac, ogg, opus, wav, flac
  • Video: mp4, webm, mkv, mov, m4v, 3gp, avi
  • Text / TTS: txt, md, markdown, log, csv, json, xml, html, rtf, ini, cfg, conf, yaml, toml
  • Playlists: m3u, m3u8

Playing on the Glasses

The easiest way: tap the Media Library tile in your TapLink Dashboard (Navigation / Entertainment section) — it's added automatically on install.

If the tile is missing, click 📺 Add to Glasses Dashboard in the toolbar above, then re-launch TapBrowser on the glasses.

Tapping ▶ Play on any playlist also works — it gives you a direct URL for advanced use.

Range requests (seeking) are fully supported.

📷 Import DCIM photos from glasses (USB) if grant flow on glasses isn't working
  1. Plug the glasses into your desktop with a USB cable.
  2. On the glasses, pull down the notification shade and switch USB mode to File transfer (MTP).
  3. On your desktop, open the glasses storage in Finder/Explorer and navigate to Internal storage › DCIM › Camera.
  4. Drag the photos / videos you want into the upload area above (or click and pick them).

Photos save to Media/Photos/ and videos to Media/Videos/ on the glasses, where they appear in the TapInsight gallery alongside saves from "save this photo".
