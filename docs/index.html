Capabilities

An instrument for understanding

Interlocking tools turn the X3 Pro from a display into a research companion — now with more personal avatars, faster camera control, editable browser workflows, and cleaner agent handoffs.

Customizable Avatars

Personalize the assistant presence with avatar controls in the companion experience, so the HUD feels more like your own instrument.

Left-Arm Camera Toggle

Tap the left arm to toggle the camera on when you need vision, then drop back to audio-first use when you want privacy or battery savings.

Editable Bookmarks

Edit TapBrowser bookmarks directly from the companion app, keeping the glasses dashboard useful without manual file surgery.

Tighter Agent Integration

Gemini, TapClaw, OpenClaw, TapBrowser, and media tools hand off more deliberately, reducing stale context and wrong-media launches.

Gemini AI Assistant

Text + vision plus live voice conversation. Point the camera, ask a question, and the assistant answers while seeing exactly what you see.

Gesture Controls

Tap, double‑tap, swipe on the temple touchpad — navigate, scroll, select, go back. Hands‑free by design.

TapRadio

Internet radio optimized for the 960×480 display. 18 curated stations, favorites, genre tabs, and 30,000+ more from Radio Browser.

TapBrowser

A full web browser on your temples: dashboard quick‑launches, bookmarks, desktop/mobile switch, and a QR scanner for one‑glance URL entry.

TapClaw + OpenClaw

Link the glasses to an OpenClaw agent on your Mac, Linux, or Windows host. Voice‑directed tool use, smart‑home control, scene analysis.

Image Relay

Camera frames stream to a local HTTP service your agent can read — every observation permanently archived in dated folders.

Companion Web App

Configure the glasses from any phone or laptop over Wi‑Fi — API keys, OAuth, TapRadio sync, TapClaw gateway, HUD settings.

Media Library & Playlists

Play local audio, video, text, and .m3u playlists from the glasses, with companion-side uploads, playlist editing, and Gemini TTS for readable files.

HUD Heartbeat Ticker

A scrolling status line that surfaces what your OpenClaw agent is doing in real time — and parks the last message so you can read it.

Setup

Connect to the companion app

The companion runs on the glasses themselves — open it from your phone or laptop and tune every setting from one place.

  1. USB · Recommended

    Forward the companion port

    Plug the X3 Pro into your computer, then establish a local port forward over ADB:

    adb forward tcp:19110 tcp:19110

  2. Open the companion in your browser

    Head to the local HTTPS endpoint:

    https://localhost:19110/

  3. Accept the self‑signed certificate warning

    The glasses use a locally‑generated TLS certificate. Your browser will flag it as unknown — click Advanced → Proceed. This is one‑time per device.

  4. Wi‑Fi · Alternate

    For Wi‑Fi, try the HTTPS URL first

    If you'd rather go wireless, your computer and the glasses need to share a network. Find the glasses' IP in Settings → WiFi, then open:

    https://<glasses-ip>:19110/

    Accept the certificate warning once, and you're in. If the device falls back to non‑TLS, use http://<glasses-ip>:19110/ instead.

  5. Keep USB forwards sticky

    The port forward drops when the glasses disconnect, reboot, or ADB restarts. The bundled helper re‑establishes it automatically:

    ./setup_usb.sh --watch

What you'll configure

  • Setup — Gemini API key, OAuth, model, system prompt, HUD
  • Browser — bookmarks, supported media types
  • Dashboard — quick‑launch tiles for TapBrowser
  • Library — upload local media, edit or auto‑generate .m3u playlists, restore the Media Library dashboard tile
  • TapRadio — search, favorites, and push station list to glasses
  • TapClaw — OpenClaw gateway URL, Cloudflare Tunnel, image relay, saved photo gallery
  • Diagnostics — Test Location, Test Traffic

Why

Old curiosity,
new instruments.

For thousands of years, people read the sky by eye and catalogued the world through notched bones, painted stones, and whispered songs. Observation is ancient technology.

TapInsight belongs to that same tradition, only with an extra pane of glass and a small AI on your temple. Point, ask, and listen — the glasses become a field notebook that writes itself while you work.

Understanding begins with paying attention. The rest is just instrumentation.
