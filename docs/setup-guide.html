1What you need

⏱ 2 minutes to check

  • RayNeo X3 Pro AR glasses (the only tested device).
  • A computer (Mac, Windows, or Linux) with a USB-C cable — used once for install, and optionally to host the media relay.
  • A Google account for a free Gemini API key (this powers the voice assistant).
  • Wi-Fi that both the glasses and your computer can join.
Tip Everything optional really is optional. A working voice assistant with HUD, captions, and the media library needs only the Gemini key. Cloudflare, Python, and agents come later — or never.

2Get your API keys

⏱ 5–10 minutes

TapInsight has no backend — it talks directly to AI services using your keys, which you paste into the companion app in Step 6. You only need the first one to start:

Keep keys private Treat each key like a password. TapInsight stores them only on the glasses; never commit them to a public repository.

3Prepare the glasses

⏱ 5 minutes

Enable Developer Mode

On the glasses (or through the RayNeo phone app, depending on firmware): Settings → About → tap the build number 7 times. You'll see "You are now a developer."

Enable USB debugging

Settings → Developer options → USB debugging → On.

Install ADB on your computer

# macOS (Homebrew)
brew install android-platform-tools

# Windows (winget)
winget install Google.PlatformTools

# Linux (Debian/Ubuntu)
sudo apt install android-tools-adb

Plug the glasses in and confirm they're visible (accept the fingerprint prompt in the glasses if asked):

adb devices
# → List of devices attached
#   1234567890ABCDE   device

4Install TapInsight

⏱ 2 minutes (APK) or ~10 minutes (build from source)

Option A — sideload the release APK (easiest)

Download TapInsight-0.2b.apk from the Releases page, then:

adb install -r TapInsight-0.2b.apk

Option B — build from source

git clone <this repository>
cd TapInsight
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
Build requirements JDK 17 and the Android SDK (Android Studio installs both). No other secrets or properties are needed to build.

5First boot & permissions

⏱ 3 minutes

Launch TapInsight from the glasses' app list. On first run:

  • Grant microphone (voice assistant), camera (vision on demand), and notification permissions when prompted.
  • You'll see the TapInsight boot splash — starfield, a fun fact typing itself out, and "GLASSES ONLINE".
  • Set your swipe unlock code on the lock screen the first time it appears.

After unlock you're in the unipanel HUD: clock and battery up top, the assistant avatar, browser panel, and the status ticker ("Assistant ready").

6The companion app

⏱ 5 minutes

The glasses run a small web server on your Wi-Fi. Configuration happens in any browser on your phone or computer — no extra app to install.

  1. Make sure the glasses are on the same Wi-Fi as your phone/computer.
  2. The HUD shows the companion address (e.g. http://192.168.1.42:8765). Open it in a browser.
  3. Paste your Gemini API key into the key field and save. Add any optional keys the same way.
  4. Browse the toggles: HUD items (calendar, tasks, news, AQI), caption preferences, readout voice, refresh intervals — every feature is documented inline.
Demo: checking it worked After saving the Gemini key, the HUD ticker should read "Assistant ready" within a few seconds. If it shows an error chip instead, re-check the key.

Where notifications arrive

Everything notification-shaped lands in one place: the bell at the top of the HUD, right of the date. New items turn the bell amber with a red unread badge; the list survives reboots. Tap the bell to roll the panel down (it auto-closes after ~10s); tap any item to open it as a reader card; tap the card again to hear it read aloud. Agent replies, calendar/task reminders, and remote pushes through your relay's /notify endpoint all use this same bell — see Step 8 for receiving notifications away from home.

8Media relay + Cloudflare tunnel (optional)

⏱ 20–30 minutes · needs a computer that stays on + a domain you own

The relay is a single Python file that runs on your computer. It gives TapInsight two superpowers:

  • File staging — agents (or you) drop music, videos, and notes into a folder; the glasses pull them into the Media Library from anywhere.
  • Remote notifications — bell notifications reach the glasses even when they're away from your home network.

8.1 Run the relay locally

cd tools
python3 image_relay.py
# → relay listening on http://0.0.0.0:18790

Test it from the same machine:

curl http://localhost:18790/media-index.json
# → {"ok": true, "files": [...]}

8.2 Publish it with a Cloudflare tunnel

A (free) Cloudflare account and a domain you own turn that local port into a stable public URL like https://relay.your-domain.com — no port forwarding, no exposed home IP.

  1. Add your domain to Cloudflare (free plan) and install cloudflared: 
    # macOS
brew install cloudflared
cloudflared tunnel login
  2. Create the tunnel and route a subdomain to it: 
    cloudflared tunnel create tapinsight-relay
cloudflared tunnel route dns tapinsight-relay relay.your-domain.com
  3. Create ~/.cloudflared/config.yml: 
    tunnel: tapinsight-relay
credentials-file: /Users/you/.cloudflared/<tunnel-id>.json
ingress:
  - hostname: relay.your-domain.com
    service: http://localhost:18790
  - service: http_status:404
  4. Run everything (relay + tunnel), telling the relay its public name: 
    export RELAY_PUBLIC_BASE="https://relay.your-domain.com"
python3 tools/image_relay.py &
cloudflared tunnel run tapinsight-relay
  5. Verify from your phone (Wi-Fi off, on mobile data): 
    https://relay.your-domain.com/media-index.json

8.3 Make it permanent (macOS)

tools/install-relay.sh installs the relay as a login service (launchd) so it survives reboots. Run it once and forget it.

8.4 Point the app at your relay

Two ways — either works:

  • Runtime: in the companion app, set your agent endpoint / relay base to https://relay.your-domain.com.
  • Build time: add TAPINSIGHT_RELAY_BASE=https://relay.your-domain.com to ~/.gradle/gradle.properties and rebuild — the app then uses it as the default everywhere.
Security The relay supports a session token shared with the glasses (set it in the companion app). Anything in your staged-media folder becomes reachable through your tunnel — don't stage files you wouldn't want fetched, and keep the token set.

9AI agents (optional)

⏱ depends on your agent setup

If you run a personal AI agent (an OpenClaw-style session, a Hermes-style assistant, or anything with an HTTP endpoint), TapInsight can route voice requests to it by name and read the answer aloud:

Live demo — agents
"Hermes, what's the latest on the weather this weekend?"
Ticker: "Asking Hermes…" → "Hermes working… 10s" → the reply is read aloud and lands in the notification bell.
"Hermes." (just the name)
"Yes?" — ask your question now; it routes straight to Hermes.

Configure your agent endpoints (URL + token) in the companion app's agent section. The endpoint host is also how the app derives your relay address automatically (relay.<your-domain>).

Troubleshooting

SymptomFix
Assistant doesn't respond to the tapCheck the Gemini key in the companion app; watch the HUD connection chip. adb logcat -s GeminiVoicePipe shows the session lifecycle.
Voice cuts out mid-question, then answers a moment laterThat's the auto-reconnect replaying your question after a server-side session drop — working as intended.
No captions in dim modeCaptions need CC enabled on the YouTube video itself; not all videos have captions. Radio lyrics need a song-ID match.
Companion page won't loadSame Wi-Fi? The address changes when your router reassigns IPs — check the HUD for the current one.
Relay URL 404s from outsidecloudflared tunnel run must be running; test localhost:18790 first, then the tunnel hostname.
Two TapInsight installs misbehave togetherRun one at a time — both serve the companion app on the same LAN port.
Install fails with signature erroradb uninstall the old build first, or use adb install -r -d.

FAQ

Does TapInsight send my data anywhere?

Only to the AI services you configure, using your own keys. There is no project-run server; the optional relay is your machine, your domain.

Do I need the relay/Cloudflare part?

No. It's only for agent file delivery and away-from-home notifications. Everything else works without it.

What does it cost to run?

The Gemini free tier covers casual use. Cloudflare tunnels are free. Optional services (Groq, AudD, Fish) have their own free tiers or low-cost plans.

Other glasses? Phones?

Built for RayNeo X3 Pro's binocular display and temple-pad gestures. It may install elsewhere, but layout and gestures assume the X3 Pro.

How do I update?

Download the new APK and adb install -r over the old one — settings and media survive.
