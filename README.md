# TapInsight

TapInsight is an open-source AI companion for the RayNeo X3 Pro AR glasses, built around a Gemini Live voice assistant that can see through the glasses' camera on demand and speaks its answers back through a live heads-up transcript. It layers a floating HUD (clock, weather, calendar, tasks, news, and a notification bell), a distraction-free dim mode with live closed captions for accessibility, a local media library with an internet radio player that does live song identification and synced lyrics, and an optional bridge to a self-hosted AI agent for more complex requests. The app runs entirely on hardware the user owns, using API keys the user supplies directly, with no backend of its own.

## Controls

- Tap the avatar orb (left temple tap) to talk to the voice assistant
- Tap the eye icon to toggle dim mode
- Swipe up/down on the temple pad to open or dismiss the breathing visualizer
- Tap the notification bell to view and act on notifications
